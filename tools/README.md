# Tools

This folder contains some tools to make the creating of FSH questionnaires less maddening.


## FormPreview

FormPreview is a small Vite + nodejs app that automagically recompiles the fsh files in the `input` folder. The renderer is pinned to the same version that is currently used by Orca.


## TIDE

TIDE is an attempt at a small templating engine in C# to make FSH files somewhat smaller and more manageable. The Atrial Fibrillation form was the first that used it. Many more templates could be added make the FSH files smaller and, in my opinion, easier to read. 

## fsh.tmLanguage.json

Is a syntax highlighting file for SublimeText. It was converted via LLM from the Vscode version.
